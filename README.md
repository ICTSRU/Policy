# منصة السياسات · ICTD Policy Platform

صفحة الدخول إلى منصة السياسات في الإدارة التنفيذية للاتصالات وتقنية المعلومات — جامعة سليمان الراجحي.

- المنصة نفسها تعمل على Google Apps Script، ومتاحة لحسابات **@sr.edu.sa** فقط.
- هذه الصفحة لا تحتوي بيانات. وظيفتها شرح طريقة الدخول وتحويلك إلى صفحة تسجيل الدخول من Google.
- كلمة المرور تُكتب في صفحة Google فقط.

الإعداد: عدّل كتلة `CONFIG` أعلى `index.html` (`WEB_APP_URL` · `TITLE` · `SUBTITLE` · `VERSION` · `KEY`).
لإظهار الصفحة مجددًا بعد اختيار «تخطَّ هذه الشاشة» افتح `…/Policy/#login`.
